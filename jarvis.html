01 // ARCHITECTURE & PIPELINE

How JARVIS Operates

Event-driven autonomous pipeline combining WhatsApp Web, sub-millisecond intent extraction, local LLM intelligence, and background cron intervals.

STEP 01
WhatsApp Listener
Listens via main.js with phone whitelist security (+60176001484) and anti-looping caches.
STEP 02
Intent & Date Parser
Fast regex + relative date resolver (intents.js) parsing "tomorrow", "Saturday 3pm", "in 30 mins".
STEP 03
Execution Engines
Direct SQLite operations, safe shell execution (cmd_runner.js), or live web search (search.js).
STEP 04
Local LLM Summaries
Ollama qwen2.5:3b synthesizes search results, executive command briefings, and natural chats.
STEP 05
60s Proactive Cron
Monitors due reminders and triggers 3-stage calendar event notifications to WhatsApp automatically.
