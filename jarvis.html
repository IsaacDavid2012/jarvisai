01 // ARCHITECTURE & UNDER THE HOOD

How JARVIS Is Built & Operates

An event-driven, autonomous pipeline combining local offline AI, headless web scraping, persistent relational storage, and cron schedulers.

STEP 01
WhatsApp Web.js Client
Main listener in main.js with typing emulation, session auth, and security whitelist filters.
STEP 02
Memory & Intent Parser
Silently extracts learned habits (memory.js) and classifies intent into 12 core categories (intents.js).
STEP 03
Local LLM & Engines
Ollama neural-chat generates humanlike WhatsApp messages, search summaries, and quotes.
STEP 04
SQLite3 Storage
Persistent storage across 9 relational tables: events, tasks, notes, memories, contacts, templates, queue.
STEP 05
60s Proactive Cron
Dispatches due scheduled messages, checks unanswered follow-ups, and triggers calendar alerts.
02 // CAPABILITIES & SUITE

Core Systems & Features

Built to empower Isaac's daily workflow across media production, IT studies, infrastructure management, and music.

INTERACTIVE LIST MESSAGE

Clickable Menu & Guided Flows

Texting "hi" or "menu" opens a native WhatsApp interactive list widget. Clicking an action initiates a step-by-step state machine with input validation and cancellation guards.

User: "menu" JARVIS: [Sends interactive List widget] User: [Clicks "📝 Draft Message"] JARVIS: "Who should I send this to?"
INTELLIGENT MESSAGING

AI Drafting & Relative Scheduling

Supports 1-shot instant sending ("tell Mark I'm 10 mins late") and iterative draft review ("make it more casual"). Relative date engine schedules messages at exact MYT timestamps.

• "tell Mark I'll be 10 mins late" • "draft message for Sarah about rates" • "send this at 3pm tomorrow"
RESPONSE MONITOR

Auto-Followup Tracking

Monitors outbound messages. If a recipient remains silent after a specified threshold (e.g. 24 hours), JARVIS sends an auto-reminder and alerts Isaac with an escalation notification.

• "remind me if Mark doesn't reply in 24h" • 24h later: Sends follow-up to client • Alerts Isaac: ⏰ Mark hasn't replied
CALENDAR & REMINDERS

3-Stage Proactive Reminders

Parses natural relative dates without UTC day shifts. Fires 3 distinct notifications: Day-Of Morning, 2 Hours Before (with client SMS alert), and 15 Minutes Imminent Start.

• "Got a shoot with Sarah Saturday 3pm" • Stage 1: Day-Of Morning Digest • Stage 2: 2h Before (Alerts Client) • Stage 3: 15m Before Start
HEADLESS PUPPETEER

Live Chromium Web Search

Headless Chromium scrapes DuckDuckGo HTML directly, bypassing CAPTCHAs and bot blocks. Generates executive AI summaries with direct clickable source URLs.

• "What is the latest AI model in 2026?" • Scrapes live HTML via Chromium • Summarizes & appends 🔗 Top Sources
REMOTE INFRASTRUCTURE

Remote Shell & Health Checks

Execute shell commands directly from WhatsApp with interactive TUI guards (!exec uptime). Continuous ICMP/HTTP monitoring across Friday, Alpha, and JARVIS nodes.

• "!exec df -h" • "!cmd docker ps" • "server status" (Friday, Alpha, JARVIS)
